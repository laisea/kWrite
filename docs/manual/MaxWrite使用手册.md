# MaxWrite 超长篇工作台 — 使用手册

> 适用版本：截至 2026-05-14 的当前仓库实现  
> 适用对象：需要管理 2000+ / 5000+ / 10000+ 章超长篇结构的用户

---

## 一、MaxWrite 是什么

MaxWrite 是专门给超长篇小说用的结构管理工具。它帮你搞定这几件事：

- **规划全书骨架** — 题材、主角、篇卷怎么分
- **按批次推进** — 不用一次摊开全书，一窗口一窗口来
- **AI 帮你细化** — 自动生成章节计划、草稿
- **跟写小说联动** — 把窗口下发到写小说工作台，写完再回收
- **对比导出** — 计划 vs 草稿 vs 定稿，随时导出

**一句话总结：别管全书，只管当前这一块。**

如果你的项目只有几百章，直接用"写小说"工作台更省事。

## 二、界面长什么样

打开 MaxWrite 后，你会看到这样的布局：

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶部工具栏：书名 · 任务队列 · 日志 · 设置 · 说明 · 导入/导出                    │
├──────────────┬───────────────────────────────────────────────────────────────┤
│ 左侧导航      │ 上面是摘要条：当前阶段、进度、推荐动作                         │
│ 总览          ├───────────────────────────────────────────────────────────────┤
│ 蓝图          │ 中间是主工作区：                                             │
│ 窗口          │ 按左侧导航切换 总览/蓝图/窗口/章节/导出                        │
│ 章节          │                                                               │
│ 导出          │ 任务队列、日志、设置这些都藏在弹窗里                           │
└──────────────┴───────────────────────────────────────────────────────────────┘
```

### 各区域是干嘛的

| 区域 | 干嘛用的 | 你会经常干啥 |
| --- | --- | --- |
| 顶部工具栏 | 全局操作和后台状态 | 看队列、看日志、改设置、导入导出 |
| 左侧导航 | 切换工作区 | 总览、蓝图、窗口、章节、导出 |
| 摘要条 | 快速了解当前状态 | 看进度、定位当前窗口、执行推荐动作 |
| 主工作区 | 干活的地方 | 改蓝图、展开窗口、细化章节、生成草稿 |
| 弹窗 | 低频操作 | 暂停队列、重试任务、看日志 |

### 左侧导航有 5 个页面

| 页面 | 用来干嘛 |
|------|----------|
| 总览 | 看看现在到哪一步了，下一步该干嘛 |
| 蓝图 | 设置全书结构、篇卷骨架 |
| 窗口 | 按卷/窗口推进章节展开 |
| 章节 | 单章细化、草稿、编辑、版本管理 |
| 导出 | 对比检查和整书/章节导出 |

## 三、完整操作流程

整个流程是这样的：

```
创建书册 → 书册总览 → 书级蓝图 → 重建骨架 → 窗口推进 → 展开章节 → 章节工作台 → 批量细化 → 生成草稿 → 编辑定稿 → 导出
                                                                                                                                                              ↓
                                                                                                                                                     （可选）下发到写小说 → 完成后回收
```

### 第 1 步：创建书册

**在哪：** 工作台首页 → 新建工程 → 选「MaxWrite 超长篇」

**要填的东西：**

| 字段 | 填啥 |
|------|------|
| 书名 | 你的作品叫啥 |
| 题材 | 玄幻/都市/科幻/仙侠... |
| 主角 | 主角是谁，简单描述下 |
| 主题 | 这本书讲啥核心主题 |
| 世界锚点 | 世界观的基础设定 |
| 笔调 | 叙事风格，比如轻松/严肃/热血 |
| 目标章数 | 你打算写多少章 |
| 章均字数 | 每章大概多少字 |
| 每卷章数 | 一卷多少章 |
| 每窗章数 | 一个窗口多少章 |
| 篇跨度 | 一篇包含几卷 |
| 工作目录 | 文件存哪 |
| 一句话梗概 | 用一句话概括这本书 |

**懒得填？用模板：**

| 模板 | 适合多大规模 | 默认结构 |
|------|--------------|----------|
| 超长篇 2000 | 2000-3000 章 | 每卷约 80 章，每窗约 20 章 |
| 长征篇 5000 | 5000 章级 | 每卷约 100 章，每窗约 30 章 |
| 万章架构 | 10000+ 章 | 每卷约 120 章，每窗约 40 章 |
| 自定义 | 特殊规模 | 手动控制 |

选好模板，填完参数，点「创建目录工程」就搞定了。

---

### 第 2 步：书册总览（看看现在到哪了）

**在哪：** 左侧导航 → 总览

这个页面就是个仪表盘，不让你编辑，只告诉你：

- **现在到哪了** — 引导卡片显示你在 5 个阶段的哪一步
- **下一步干嘛** — 一键跳转到推荐的工作区
- **整体进度** — 展开了多少窗口、细化了多少章节、定稿了多少

**你要做的：** 看看引导卡片，点「前往推荐工作区」，或者直接从左侧导航切换。

---

### 第 3 步：书级蓝图（搭骨架）

**在哪：** 左侧导航 → 蓝图

**这里干啥：**

1. **改设定** — 调整题材、主角、参数等
2. **保存参数** — 只保存你填的内容，不重建结构
3. **重建整书蓝图** — 用当前参数重新生成篇/卷/窗口骨架
4. **看看骨架** — 确认篇的戏剧性命题、卷的切分是否合理

> 注意：保存参数 ≠ 重建结构。改了参数后页面会提示「蓝图待刷新」，需要手动点「重建整书蓝图」才会生效。

**操作顺序：**
```
改设定 → 保存参数 → 检查骨架 → 不满意就改 → 满意后重建蓝图
```

---

### 第 4 步：窗口推进（展开章节）

**在哪：** 左侧导航 → 窗口

**操作步骤：**

1. **选卷** — 在工具栏下拉选择当前卷
2. **选窗口** — 点击窗口列表中的目标窗口
3. **看看窗口详情** — 右侧显示摘要、锚点、收尾钩子
4. **展开本窗** — 为当前窗口生成所有章节

**有哪些按钮可以点：**

| 按钮 | 干嘛的 | 啥时候用 |
|------|--------|----------|
| 展开本窗 | 生成当前窗口的章节 | ✅ 优先用这个 |
| 重建本窗 | 重新生成窗口计划，清空已有章节 | 方向搞错了才用 |
| 展开整卷 | 批量展开当前卷所有窗口 | 想清楚了再用，任务量大 |

**操作顺序：**
```
选卷 → 选窗口 → 看摘要/锚点/钩子 → 确认 → 展开本窗 → 进入章节工作台
```

---

### 第 5 步：章节工作台（细化和写草稿）

**在哪：** 左侧导航 → 章节

**布局：** 左边是章节列表 + 写小说桥接面板，右边是选中章节的详情。

#### 批量操作（顶部工具栏）

| 按钮 | 干嘛的 |
|------|--------|
| 重建本窗章节 | 清空当前窗口所有章节并重新生成 |
| 批量细化本窗 | 对所有章节执行 AI 细化（生成目标/冲突/节拍） |
| 批量生成草稿 | 对所有已细化章节生成 AI 草稿 |

#### 单章操作（4 个标签页）

| 标签页 | 看到啥 | 能干嘛 |
|--------|--------|--------|
| **计划** | 目标、冲突、反转、节拍、备注 | 细化单章、跳转对比 |
| **AI 草稿** | AI 生成的草稿正文 + 字数 | 生成/重新生成草稿、载入编辑器、采纳为定稿 |
| **合并预览** | 当前输出（优先定稿，无定稿回退草稿） | 跳转对比、导出工作包 |
| **编辑器** | 正文编辑区 + 版本命名 | 保存定稿、保存命名版本、恢复版本 |

#### 其他信息

- **提示词包** — 当前章节的完整提示词，可以复制
- **版本历史** — 所有版本快照，可以查看差异或恢复

**操作顺序：**
```
展开窗口后 → 批量细化 → 逐章检查计划 → 生成草稿 → 编辑定稿
```

---

### 第 6 步：写小说桥接（可选）

如果你想用更专业的正文生产流程，可以把窗口下发到写小说工作台。

**在哪：** 章节工作台左侧 → 写小说桥接面板

**怎么用：**

```
MaxWrite 窗口                    写小说工作台
     │                                │
     │── 下发到写小说 ──────────────→  │ 创建项目，携带章节结构
     │                                │ 你在写小说中完成正文
     │←── 回收写作结果 ─────────────  │ 正文、审查结果写回 MaxWrite
     │                                │
```

**具体步骤：**

1. 在章节工作台选中一个窗口
2. 点击桥接面板的「下发到写小说」
3. 系统自动创建写小说项目，带上：窗口结构、章节计划、锚点、已有草稿
4. 点击「进入写小说项目」跳转到写小说工作台完成正文
5. 完成后回到 MaxWrite，点击「回收写作结果」
6. 回收内容：正文、章节合同、审查结果、结构化章后信息

> 一个窗口绑定一个写小说项目。不同窗口可以绑定不同的写小说项目。

---

### 第 7 步：对比与导出

**在哪：** 左侧导航 → 导出

**三种对比模式：**

| 模式 | 左边看啥 | 右边看啥 | 干嘛用 |
|------|----------|----------|--------|
| 计划 vs 草稿 | 章节计划 | AI 草稿 | 检查草稿有没有兑现计划 |
| 草稿 vs 定稿 | AI 草稿 | 人工定稿 | 看看人工改得好不好 |
| 版本对比 | 历史版本 | 当前输出 | 长线写作回溯 |

**导出选项：**

| 导出啥 | 说明 |
|--------|------|
| 导出章节工作包 | 单章完整工作包（设定 + 计划 + 草稿 + 定稿 + 版本） |
| 导出整书 JSON | 完整书册数据（归档/迁移/版本留存） |
| 复制提示词包 | 复制当前章节的 AI 提示词 |

## 四、辅助功能

### 4.1 任务队列

**在哪：** 工具栏 → 队列按钮（带未完成数量徽章）

所有结构操作和章节操作都会进入队列，一个一个执行。

| 能干嘛 | 说明 |
|--------|------|
| 暂停/恢复队列 | 大改结构时先暂停，确认后恢复 |
| 重试失败任务 | 单个任务失败时可以重试 |
| 移除任务 | 从队列中移除 |

### 4.2 操作日志

**在哪：** 工具栏 → 日志按钮（或快捷键 `Cmd/Ctrl + L`）

记录所有操作历史，支持按类型筛选和清空。

### 4.3 工作台设置

**在哪：** 工具栏 → 设置按钮（或快捷键 `Cmd/Ctrl + ,`）

| 设置组 | 干嘛的 |
|--------|--------|
| 配置概览 | 当前模型和基本配置 |
| 阶段模型 | 5 个阶段可以绑定独立模型 |
| 队列协作 | 自动执行、保留已完成、写小说模型沿用策略 |
| 导出偏好 | 工作包是否附带提示词包和版本历史 |

### 4.4 使用说明

**在哪：** 工具栏 → 说明按钮（💬 图标）

弹窗显示主路径说明，就是本手册的核心流程概要。

### 4.5 导入方案

**在哪：** 工具栏 → 导入方案按钮

从之前导出的整书 JSON 文件恢复方案。

## 五、5 个阶段对应的 AI 任务

MaxWrite 的 5 个阶段对应不同的 AI 任务，每个阶段可以绑定独立模型：

| 阶段 | 对应页面 | AI 干啥 |
|------|----------|---------|
| 书级蓝图 | 蓝图 | 生成篇/卷/窗口骨架 |
| 窗口展开 | 窗口 | 生成窗口摘要/锚点/钩子 |
| 章节细化 | 章节 | 生成章节目标/冲突/节拍 |
| 草稿生成 | 章节 | 生成章节正文草稿 |
| 对比复盘 | 导出 | 检查计划兑现和版本差异 |

没绑定独立模型的话，会用书级默认模型。

## 六、推荐操作节奏

```
① 创建书册（选模板 → 填参数 → 创建）
       ↓
② 蓝图（改设定 → 保存 → 重建蓝图）
       ↓
③ 窗口（选卷 → 选窗 → 展开本窗）
       ↓
④ 章节（批量细化 → 逐章检查 → 生成草稿 → 编辑定稿）
       ↓
   ┌───┴───┐
   │       │
⑤A 直接   ⑤B 下发到写小说 → 完成后回收
   │       │
   └───┬───┘
       ↓
⑥ 导出（对比检查 → 导出工作包/整书 JSON）
```

**日常循环：** 步骤 ③→④→⑤ 按窗口重复，直到全书完成。

**定期操作：** 记录快照、导出整书 JSON 做备份。

## 七、常见问题

### Q: 几百章的项目需要用 MaxWrite 吗？

不需要。500 章以内直接用"写小说"工作台更高效。

### Q: 创建后要立刻展开所有章节吗？

不要。MaxWrite 的设计就是避免一次性摊开全书。按窗口逐个推进。

### Q: 展开本窗和展开整卷选哪个？

优先「展开本窗」。只有非常确定整卷都要推进时才用「展开整卷」。

### Q: MaxWrite 的草稿能当最终正文吗？

可以作为起点。更稳的做法是下发到写小说工作台完成真实正文生产。

### Q: 导出的 JSON 和普通项目包一样吗？

不一样。MaxWrite 导出的是自己的整书 JSON 格式，和写小说的项目包格式不同，不要混用。

### Q: 一个窗口能绑定多个写小说项目吗？

不能。一个窗口绑定一个写小说项目。但不同窗口可以绑定不同的写小说项目。
